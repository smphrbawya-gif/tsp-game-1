So what is the TSP?TSP คืออะไร?

Say you are a salesman. You have to visit several customers in one day, stop at each place once, and end up back home. The question is simple: which order gives you the least travelling? That puzzle is the Travelling Salesman Problem, or TSP.

สมมติว่าคุณเป็นพนักงานขาย วันนี้ต้องไปหาลูกค้าหลายที่ แต่ละที่แวะแค่ครั้งเดียว แล้วต้องกลับมาถึงบ้านด้วย คำถามคือไปลำดับไหนถึงจะเดินทางน้อยที่สุด นี่แหละคือ Travelling Salesman Problem หรือ TSP

It sounds easy, but computer scientists have been stuck on it for a long time. Add a few more places and the number of possible routes explodes. Meanwhile the same problem shows up everywhere: delivery trucks, garbage trucks, even machines that drill circuit boards.

ฟังดูง่าย แต่นักคอมพิวเตอร์ปวดหัวกับมันมานานมาก พอที่ให้ไปเพิ่มขึ้นนิดเดียว จำนวนเส้นทางก็พุ่งขึ้นเร็วมาก ทั้งที่ปัญหาแบบนี้เจอได้ทุกที่ ทั้งรถส่งของ รถเก็บขยะ หรือเครื่องเจาะแผงวงจร

Why is it so hard?ทำไมถึงยาก?

Because the number of routes grows crazy fast. With n places there are about (n-1)!/2 different round trips.

เพราะจำนวนเส้นทางโตเร็วเกินคาด ถ้ามี n ที่ จะมีเส้นทางไปกลับที่ไม่ซ้ำกันประมาณ (n-1)!/2 แบบ

Even if a computer could check a billion routes per second, 20 places would still take about two years. That is why TSP is called NP-hard: nobody knows a shortcut that always finds the best answer.

ต่อให้คอมตรวจได้พันล้านเส้นทางต่อวินาที แค่ 20 ที่ก็ยังใช้เวลาเกือบสองปี เลยจัดให้ TSP เป็นปัญหา NP-hard คือยังไม่มีใครรู้ทางลัดที่ได้คำตอบดีที่สุดเสมอ

Four places A, B, C, D. The numbers on the lines are distances. Starting from A there are only 3 routes to compare:

มี 4 ที่ คือ A B C D ตัวเลขบนเส้นคือระยะทาง เริ่มจาก A จะมีให้เลือกแค่ 3 แบบ:

Routeเส้นทางTotalรวม

If you always walk to the nearest unvisited place you get A → B → D → C → A = 80, which happens to be the best. That is luck, though. With more places this trick starts failing. Try the hint button in the game and see if you can beat it.

ถ้าไปที่ใกล้สุดทุกครั้ง จะได้ A → B → D → C → A = 80 ซึ่งดีที่สุดพอดี แต่นั่นแค่โชคดี พอที่เยอะขึ้นวิธีนี้ก็เริ่มพลาด ลองกดปุ่มคำใบ้ในเกมแล้วดูว่าชนะมันได้ไหม

Why crossing lines are badทำไมเส้นที่ตัดกันถึงไม่ดี

Look at the left picture. The route makes an X. If you swap the order of two stops, you get the picture on the right, and the total distance always gets shorter. So the best route never crosses itself. Programmers use the same idea in a method called 2-opt: find a crossing, fix it, repeat. You can do the same while playing.

ดูรูปซ้าย เส้นทางตัดกันเป็นรูปกากบาท ถ้าสลับลำดับสองจุดจะได้เหมือนรูปขวา และระยะรวมจะสั้นลงเสมอ เพราะงั้นเส้นทางที่สั้นที่สุดจะไม่มีวันตัดกันเอง โปรแกรมเมอร์ก็ใช้ไอเดียนี้เหมือนกัน เรียกว่า 2-opt คือหาเส้นที่ตัดกัน แก้ แล้วทำซ้ำ ตอนเล่นเกมคุณก็ทำแบบเดียวกันได้เลย

In real life, with hundreds of stops, people rarely hunt for the perfect answer. They use a heuristic: a fast method that gives a good-enough route.

ในโลกจริงที่มีจุดแวะเป็นร้อย ๆ ที่ ไม่ค่อยมีใครหาคำตอบที่ดีที่สุดเป๊ะ ๆ กัน แต่จะใช้ heuristic คือวิธีที่เร็วและได้เส้นทางที่ดีพอ

Tips for the gameเทคนิคตอนเล่นเกม

  • Look at the whole map first and picture the route as one loop around it.
  • Finish one side of the map before crossing to the other. Zigzagging back and forth is expensive.
  • If two lines cross, undo and swap the order.
  • Press the hint, then try to beat it.
  • ดูภาพรวมทั้งแผนที่ก่อน แล้วลองนึกภาพเส้นทางเป็นวงรอบเดียว
  • เก็บฝั่งหนึ่งให้เสร็จก่อนค่อยข้ามไปอีกฝั่ง การวิ่งไปมาข้ามฝั่งเปลืองระยะมาก
  • ถ้าเส้นตัดกัน ให้ย้อนกลับแล้วสลับลำดับ
  • ลองกดคำใบ้ดู แล้วพยายามเอาชนะมัน
